## Page structure (one page, plus legal pages)

1. **Header**: logo, name, links (How it works, Install, Docs), GitHub as a secondary button.
2. **Hero**: neutral headline (candidates below), one-paragraph lede, primary button *Download* (latest release), secondary *Getting started*, a line of facts ("Offline · Windows and Linux · Apache-2.0" once the licence changes), the real screenshot (light and dark via `<picture>`).
3. **Every number shows where it stands**: budget table in the window's cell styles with the five states, icon and word each, and a legend.
4. **One model, four budgets**: Power, Mass, Thermal, Link with their rail icons; three points: offline, reproducible reports (with the real condition from claim C-04), revision compare.
5. **How this software is made**: the AI-authorship text and the personal-project statement (Phase 5 and 2 wording, shown to the owner first).
6. **Install**: segmented control Windows / Linux / From source, Copy button, SHA256 and attestation notes (Phase 6).
7. **Footer**: doc links in three columns; a line styled like the status bar; the single disclaimer; links to Privacy, Imprint (only if the owner's country needs it), Licences, Third-party notices; a short trademark note.
8. Pages: `privacy.html`, `licences.html`, `notices` (third-party), `imprint.html` (conditional), `404.html`, `/.well-known/security.txt`.

Headline candidates (no promise): "Power, mass, thermal and link budgets from one plain-text model." / "Budgets for small satellites, offline, from plain-text files." / "One spacecraft model. Four budgets. Every number traced to its input."
